# Data

The NDHS 2023-24 microdata is not included in this repository.

## Accessing the Data

1. Visit: https://dhsprogram.com/data/new-user-registration.cfm
2. Register as a new user
3. Submit a data request for: Nigeria DHS 2023-24 (NGA_2023-24_DHS)
4. Once approved, download the individual recode (IR) file

## Feature Variables Used

| Variable | Description | Categories |
|----------|-------------|------------|
| SBA | Skilled Birth Attendance | Skilled / Unskilled |
| ANC | Antenatal Care Visits | 0 / 1-3 / 4+ |
| BIRTH_INTERVAL | Preceding Birth Interval (months) | <24 / 24-47 / 48+ |
| BIRTH_ORDER | Birth Order | 1st / 2nd-3rd / 4th+ |
| CHILD_SIZE | Child Size at Birth | Small / Average / Large |
| MAT_AGE_FIRST | Maternal Age at First Birth | <18 / 18-24 / 25+ |
| WEALTH_INDEX | Household Wealth Index | Quintile 1-5 |
| GEO_ZONE | Geopolitical Zone | NW / NE / NC / SW / SE / SS |
| IMMUNISATION | Any Immunisation by 12-23 months | Yes / No |

## Outcome Variable

| Variable | Description | Values |
|----------|-------------|--------|
| NEONATAL_DEATH | Death within 28 days of live birth | 1 = Died / 0 = Survived |
